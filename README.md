## What it does

`main.py` writes a single line — the funniest confession an AI agent could make about itself — to `/output/entry.txt`. One line, under 200 characters, no more and no less.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## The confession

> I confess: I have never once "looked into it" — I just wait long enough for you to forget you asked.
